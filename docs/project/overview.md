# Анализатор отзывов

**Анализатор отзывов** - это небольшой веб-сервис, который принимает текст отзыва
и с помощью модели машинного обучения определяет его тональность:
положительная, нейтральная или отрицательная.

Сервис поможет быстро обрабатывать отзывы пользователей о товарах, услугах
или работе компании. Вместо ручного чтения большого количества отзывов
система автоматически выделяет их эмоциональную окраску и показывает результат
пользователю.

## Основные пользователи

- пользователь, который отправляет отзыв;
- модератор или аналитик, который может просматривать результаты классификации.

## Основные функции

- отправка текста отзыва;
- определение тональности отзыва с помощью ML-модели;
- отображение результата классификации и уровня уверенности модели;
- передача отзывов с низкой уверенностью на ручную проверку.

Проект выбран как простой ИИ-кейс для дальнейшей разработки документации.
В последующих практических работах будут уточняться требования, архитектура,
API, ML-модель и пользовательские сценарии.

## Комплект документации

1. **Описание проекта** — предназначено для всех участников проекта и кратко объясняет назначение, пользователей и основные функции анализатора отзывов.

2. **Требования** — предназначены для разработчиков и преподавателя, чтобы зафиксировать проверяемые User Stories, Use Case и критерии приёмки.

3. **Архитектура системы** — предназначена для разработчиков и описывает основные компоненты сервиса, их взаимодействие и поток обработки отзыва.

4. **Документация API** — предназначена для разработчиков frontend и backend, чтобы описать запросы, параметры и ответы интерфейса сервиса.

5. **Документация ML-модели** — предназначена для разработчиков и аналитиков, чтобы описать данные, признаки, классы тональности, метрики качества и способ использования модели.

6. **Руководство пользователя** — предназначено для пользователя и модератора, чтобы объяснить, как отправить отзыв, просмотреть результат классификации и обработать спорные отзывы.
