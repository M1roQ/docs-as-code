# API

API предоставляет доступ к функциям сервиса анализа тональности отзывов.

## Основные операции

- `POST /analysis` — отправить текст отзыва и получить результат анализа тональности;
- `GET /analysis/{analysisId}` — получить ранее сохранённый результат анализа по его идентификатору;
- `GET /models` — получить список доступных ML-моделей анализа тональности.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
