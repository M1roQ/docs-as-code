# Model Card

## Общая информация

**Название модели:** `blanchefort/rubert-base-cased-sentiment`

**Источник:** [Страница модели на Hugging Face](https://huggingface.co/blanchefort/rubert-base-cased-sentiment)

**Автор / организация:** blanchefort

**Задача модели:** классификация тональности коротких русскоязычных текстов.

**Язык:** русский.

Модель основана на `DeepPavlov/rubert-base-cased-conversational` и дообучена
на агрегированном корпусе из 351 797 текстов. Она определяет тональность текста
и возвращает один из трёх классов: нейтральный, положительный или отрицательный.

## Использование в проекте

Модель используется в сервисе «Анализатор отзывов» для определения тональности
отзывов пользователей.

Пользователь отправляет текст отзыва через `POST /analysis`. Система передаёт
текст в ML-модель, получает предсказание и преобразует его в одну из категорий:
`positive`, `neutral` или `negative`. Результат анализа, уровень уверенности,
версия модели и время создания сохраняются системой. Пользователь может получить
сохранённый результат позже через `GET /analysis/{analysisId}`.

## Входные данные

Модель принимает текст отзыва на русском языке.

Входной текст обрабатывается токенизатором модели. Максимальная длина входной
последовательности составляет 512 токенов; более длинный текст обрезается.

## Выходные данные

Модель возвращает один из трёх классов тональности:

- `NEUTRAL` — нейтральный текст;
- `POSITIVE` — положительный текст;
- `NEGATIVE` — отрицательный текст.

В проекте результат модели преобразуется в категории API:

- `NEUTRAL` → `neutral`;
- `POSITIVE` → `positive`;
- `NEGATIVE` → `negative`.

Дополнительно система может рассчитывать уровень уверенности модели
на основе вероятностей классов.

## Метрики качества

Метрики качества, такие как accuracy, precision, recall или F1-score,
не указано авторами модели на странице модели.

Поэтому перед использованием модели в реальном сервисе необходимо провести
собственную оценку на тестовой выборке русскоязычных отзывов.

## Ограничения

1. Модель предназначена для коротких русскоязычных текстов. Качество на длинных,
   сложных или узкоспециализированных отзывах может быть ниже.

2. Модель принимает не более 512 токенов. Более длинные отзывы будут обрезаны,
   поэтому часть текста может не участвовать в классификации.

3. Модель обучалась в том числе на данных социальных сетей и отзывах о товарах,
   поэтому её качество на отзывах из других предметных областей может отличаться.

4. Потенциальное ограничение для нашего проекта: модель может хуже работать
   с отзывами, содержащими большое количество эмодзи, сленга, иронии
   или смешанных мнений о разных аспектах товара или услуги.

## Не рекомендуется использовать

Модель не рекомендуется использовать для принятия важных решений без проверки
человеком, например для автоматического удаления отзывов, блокировки пользователей
или оценки качества медицинских услуг.

Также модель не предназначена для анализа текстов на языках, кроме русского,
и не должна использоваться как источник юридических, медицинских или финансовых
рекомендаций.
