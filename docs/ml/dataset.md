# Data Sheet

## Общая информация

**Название датасета:** RuReviews

**Источник:** [Репозиторий RuReviews на GitHub](https://github.com/sismetanin/rureviews)

**Назначение:** датасет предназначен для обучения и оценки моделей
классификации тональности русскоязычных отзывов о товарах.

Датасет был создан для исследования «Sentiment Analysis of Product Reviews
in Russian using Convolutional Neural Networks». Он содержит отзывы пользователей
и их тональность: отрицательная, нейтральная или положительная.

## Состав данных

**Объём:** в финальной версии датасета используется 90 000 отзывов,
по 30 000 отзывов для каждого класса: negative, neutral и positive.

**Тип данных:** текстовые отзывы на русском языке с меткой тональности.

**Основные поля / признаки:**

- текст отзыва;
- метка тональности: `negative`, `neutral` или `positive`.

Исходно отзывам присваивалась оценка от 1 до 5 звёзд. Затем пятибалльная шкала
была преобразована в три класса:

- оценки 1 и 2 — `negative`;
- оценка 3 — `neutral`;
- оценки 4 и 5 — `positive`.

## Получение данных

Данные были автоматически собраны из отзывов о товарах в категории
«Женская одежда и аксессуары» на крупном российском маркетплейсе.

В качестве меток тональности использовались оценки, оставленные пользователями.
Отзывы с одинаковым или очень похожим текстом объединялись, чтобы уменьшить
количество дубликатов.

## Предобработка

При создании датасета выполнялась очистка данных от повторяющихся отзывов.

Пятибалльная шкала оценок была преобразована в три класса тональности.
Затем из каждого класса было случайно выбрано по 30 000 отзывов,
чтобы получить сбалансированный набор данных.

## Ограничения

- Датасет собран преимущественно из отзывов об одежде и аксессуарах,
  поэтому его качество на отзывах о других категориях товаров может быть ниже.
- Метки были получены автоматически на основе пользовательских оценок,
  а не с помощью детальной ручной разметки по единым правилам.
- Граница между соседними оценками может быть субъективной: например,
  отзыв с оценкой 3 не всегда однозначно нейтральный.
- Датасет отражает отзывы об онлайн-покупках и может не покрывать отзывы
  об услугах, медицинских учреждениях или других сферах.

## Использование в проекте

Датасет связан с проектом «Анализатор отзывов», потому что он содержит
русскоязычные отзывы о товарах и их тональность.

Он может использоваться для оценки качества выбранной модели
`blanchefort/rubert-base-cased-sentiment` на русскоязычных отзывах,
а также для потенциального дообучения или калибровки модели под отзывы
конкретного сервиса.

В API проекта модель принимает текст отзыва и возвращает одну из категорий:
`positive`, `neutral` или `negative`. Эти категории соответствуют классам
датасета RuReviews.
